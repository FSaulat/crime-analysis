# Crime Analysis - SARA Model

## Data Note
The CSV file (`Crime_Data_from_2020_to_2024.csv`) is not included in this repository due to file size.

To run this code:
1. Obtain the crime data file
2. Save it as `Crime_Data_from_2020_to_2024.csv` in the same folder
3. Run `python analysis.py`

## Methods Used
- SARA model (Scanning, Analysis, Response, Assessment)
- Crime Triangle (Location, Victim, Offender)

## Key Findings
- Top crime: VEHICLE - STOLEN (11.5%)
- Hotspot: 77th Street
- Peak time: 6:00 PM / Friday
- Primary location: Streets (77.8%)
